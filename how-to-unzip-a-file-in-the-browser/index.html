How to unzip a file in the browser

You can open a ZIP archive in Chrome, Edge, Firefox, or Safari without installing software and without uploading the file to a server.

  1. Open Free ZIP Tool and stay on the Unzip tab.
  2. Drop your .zip file on the highlighted area or choose it from your device.
  3. Browse folders in the file tree, use the name filter, and preview text or images before saving.
  4. Download one file, a selection, everything as separate files, or repack a selection into a smaller ZIP.

Nothing leaves your computer during these steps. If you see an error, the file may be corrupt, password-protected, or not a ZIP at all.
